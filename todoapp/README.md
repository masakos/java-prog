
# プログラムで日時を扱うための基礎知識

## 1. 日時の表現形式（ISO 8601）

日時をプログラムで扱うときは、ISO 8601（アイエスオー 8601） という国際規格に基づいた形式がよく使われる。

例：

```
2026-10-15T03:49:39.462714400Z   # UTCの午前3時
2026-10-15T12:00:00+09:00 # +09:00：UTCより9時間進んだ時刻、つまり日本時間の正午
```

| 部分           | 意味                 |
| ------------ | ------------------ |
| `2026-10-15` | 日付（年-月-日）          |
| `T`          | 日付と時刻の区切り          |
| `03:49:39`   | 時刻（時:分:秒）          |
| `.462714400` | 秒の小数部分（ナノ秒まで表現可能）  |
| `Z`          | UTC（協定世界時）であることを示す |

ISO 8601では、日付や時刻を決められた形式で表すため、異なる国やシステム間でも日時をやり取りしやすい。

## 2. タイムゾーン（Time Zone）

タイムゾーンとは、地域ごとの標準時を扱うための仕組みである。

- 日本：`Asia/Tokyo`（日本標準時、JST）
- UTC：協定世界時（世界の時刻の基準となる時刻）

日本時間はUTCより9時間進んでいる。

例えば、UTCが午前3時なら、日本時間は正午の12時になる。

```
UTC        : 2026-10-15 03:00
日本時間   : 2026-10-15 12:00
```

同じ瞬間でも、タイムゾーンによって表示される時刻が異なる。

| 国 | タイムゾーンID（Java） | UTCとの時差 | 日本との時差 |
|---|---|---|---|
| ミャンマー | `Asia/Yangon` | UTC+6:30 | 日本より2時間30分遅い |
| タイ | `Asia/Bangkok` | UTC+7:00 | 日本より2時間遅い |
| ベトナム | `Asia/Ho_Chi_Minh` | UTC+7:00 | 日本より2時間遅い |
| イギリス | `Europe/London` | UTC+0:00（冬）／UTC+1:00（夏） | 日本より9時間／8時間遅い |
| スリランカ | `Asia/Colombo` | UTC+5:30 | 日本より3時間30分遅い |
| カンボジア | `Asia/Phnom_Penh` | UTC+7:00 | 日本より2時間遅い |
| 中国 | `Asia/Shanghai` | UTC+8:00 | 日本より1時間遅い |
| ウズベキスタン | `Asia/Tashkent` | UTC+5:00 | 日本より4時間遅い |


## 3. エポック（Epoch）

エポックとは、日時を計算するための基準となる時点である。

Javaの `Instant` などでは、次の時点が基準となる。

```
1970年1月1日 00:00:00 UTC
```

この基準時点からどれだけ時間が経過したかを使って、日時を数値として表現できる。

## 4. エポック秒（Epoch seconds）

エポック秒とは、エポックからの経過秒数である。

例えば、次のようになる。

| エポックからの経過時間 | エポック秒   |
| ----------- | ------- |
| 基準時点        | `0`     |
| 1秒後         | `1`     |
| 1分後         | `60`    |
| 1時間後        | `3600`  |
| 1日後         | `86400` |

エポック秒を使うと、日時を数値として扱えるため、日時の比較や経過時間の計算に便利である。

※ うるう秒などの扱いには注意が必要だが、通常のプログラミングではこのように理解すればよい。

## 5. Javaで日時を扱う

Javaでは、`java.time` パッケージを使用する。用途に応じてクラスを使い分ける。

| クラス             | 用途              | 例                                    |
| --------------- | --------------- | ------------------------------------ |
| `LocalDate`     | 日付              | `2026-10-15`                         |
| `LocalTime`     | 時刻              | `12:30:00`                           |
| `LocalDateTime` | 日付と時刻（タイムゾーンなし） | `2026-10-15T12:30:00`                |
| `ZonedDateTime` | タイムゾーンを含む日時     | `2026-10-15T12:30+09:00[Asia/Tokyo]` |
| `Instant`       | 世界共通の時間軸上の瞬間    | `2026-10-15T03:49:39.462714400Z`               |

例えば、現在の日時を取得するには次のように書く。

```
import java.time.LocalDate;
import java.time.Instant;

public class Main {
    public static void main(String[] args) {
        LocalDate today = LocalDate.now();
        Instant now = Instant.now();

        System.out.println(today);
        System.out.println(now);
    }
}
```

- `LocalDate.now()`：実行環境のタイムゾーンに基づく今日の日付を取得する。
- `Instant.now()`：現在の瞬間を取得する。通常、`Z` が付いたUTC基準の形式で表示される。
