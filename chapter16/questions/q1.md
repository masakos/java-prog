## 演習問題：

次のような `Task` クラスがあります。

```java
public class Task {
    private String name;

    public Task(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}
```

次の3つのタスクをTaskとしてインスタンス化してArrayListにかくのうしてください。
そのあと１つずつ、順番に取り出してタスクの名前を表示するプログラムを作成してください。

### 登録するタスク

- 課題レポートを提出する
- Javaの復習をする
- 教科書を読む

#### 実行結果

```text
----タスク一覧----
レポートを提出する
Javaの復習をする
教科書を読む
```
