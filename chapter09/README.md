## 
- 参照型を理解する
- Stringもクラス型

```
Javaの型
├─ 基本データ型（プリミティブ型）
│   ├─ int
│   ├─ double
│   ├─ boolean
│   └─ char
│
└─ 参照型
    ├─ クラス型
    │   ├─ String (Javaが用意しているクラス)
    │   ├─ Book(開発者が定義したクラス)
    │   └─ Student(開発者が定義したクラス)
    │
    ├─ 配列型
    │   ├─ int[]
    │   ├─ String[]
    │   └─ Book[]
```

- 参照型の変数には、オブジェクトを参照する情報が入っている
- 「オブジェクトそのもの」がコピーされるわけではない。
- そのため、変数をコピーすると、同じオブジェクトを参照することがある。
- 「別のオブジェクトがコピーされた」と思って変更すると、 元の変数から見えるオブジェクトも変わってしまうので注意！



## コンストラクタの特徴

コンストラクタは、**インスタンスを作成するときに、自動的に実行される特別な処理**です。

### インスタンス作成時に自動的に実行される

```java
Book book = new Book();
```

`new Book()` でインスタンスが作成されると、`Book` のコンストラクタが自動的に実行されます。


### 名前はクラス名と同じ

コンストラクタの名前は、**クラス名と完全に同じ**にします。

```java
class Book {

    Book() {
        // コンストラクタ
    }
}
```

`Book` クラスなので、コンストラクタも `Book` です。

---

### 戻り値の型を書かない

コンストラクタには、`void` を含めて**戻り値の型を書きません**。

```java
Book() {
}
```


### 引数を受け取ることができる

コンストラクタは、引数を受け取ることができます。

```java
Book(String title, int price) {
    this.title = title;
    this.price = price;
}
```

この場合、

```java
Book book = new Book("Java入門", 3000);
```

のように、インスタンスを作成するときに初期値を渡すことができます。


### ⑥ 複数のコンストラクタを作ることができる

引数の数や型が異なるコンストラクタを複数定義できます。

これを**コンストラクタのオーバーロード**といいます。

```java
Book() {
}

Book(String title) {
    this.title = title;
}

Book(String title, int price) {
    this.title = title;
    this.price = price;
}
```

---

### コンストラクタを1つも定義しない場合

クラスにコンストラクタを**1つも定義しなかった場合**は、コンパイラが自動的に、

- 引数なし
- 処理なし

のコンストラクタを用意します。

例えば、

```java
class Book {
    String title;
    int price;
}
```

と書いた場合、イメージとしては次のコンストラクタが自動的に用意されます。

```java
Book() {
}
```

### 注意

自分でコンストラクタを1つでも定義すると、**自動で用意される引数なしコンストラクタはなくなります。**

例えば、

```java
class Book {

    Book(String title) {
        this.title = title;
    }
}
```

とした場合、

```java
Book book = new Book();  // エラー
```

となります。

引数なしでも作りたい場合は、自分で定義します。

```java
Book() {
}

Book(String title) {
    this.title = title;
}
```
