
# Java演習：ProductとCategoryを作ってみよう


クラスの中に、**別のクラス型のフィールド**を持たせるプログラムを作成してください。

オンラインショップの商品をイメージしてください。

```text
商品（Product）
 ├─ 商品名
 ├─ 価格
 └─ カテゴリー（Category）
```

例えば、次のような商品をプログラムで表現します。

```text
商品名：ノートPC
価格：100000円
カテゴリー：パソコン
```

---

## STEP 1　Categoryクラスを作る

商品のカテゴリーを表す `Category` クラスを作成してください。

```java
class Category {
    String name;
}
```

## STEP 2　Productクラスを作る

商品を表す `Product` クラスを作成してください。

```java
class Product {
    String name;
    int price;
    Category category;
}
```


## STEP 3　コンストラクタを作る

`Category` クラスと `Product` クラスに、**コンストラクタ**を作成してください。

カテゴリー名を受け取り、`name` に設定するコンストラクタを作成してください。

```java
Category(String name) {
    this.name = name;
}
```

### Productのコンストラクタ

商品名、価格、カテゴリーを受け取り、それぞれのフィールドに設定するコンストラクタを作成してください。

```java
Product(String name, int price, Category category) {
    this.name = name;
    this.price = price;
    this.category = category;
}
```


## STEP 4　mainメソッドからオブジェクトを作成する

`main` メソッドから、次の商品を作成してください。

```text
商品名：ノートPC
価格：100000円
カテゴリー：パソコン
```


## STEP 5　商品情報を表示する

作成した `product` の情報を、次のように表示してください。

```text
ノートPC
100000
パソコン
```
