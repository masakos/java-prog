## 演習問題：タスク一覧をファイルから読み込む

`chapter18/data/tasks.csv` には、次のようなタスクの一覧が入っています。

```text
課題レポートを提出する,2026-11-10,0
Javaの復習をする,2026-11-12,1
教科書を読む,2026-11-15,0
プレゼン資料を作る,2026-11-20,0
```

1行が1つのタスクで、`,`（カンマ）で区切って次の順番で並んでいます。

| 1つ目 | 2つ目 | 3つ目 |
| --- | --- | --- |
| タイトル | 期限 | 完了したら `1`、まだなら `0` |

このファイルを読み込んで、**ArrayList** に入れて表示するプログラムを作ります。
いきなり全部は作らず、**STEP 1 から順番に、少しずつ機能を追加** していきます。

- STEP 1 は **みんなで一緒に** 作ります。
- STEP 2 からは、STEP 1 のプログラムに **自分で書き足して** いきます。
- 1つの STEP ができたら、**実行して結果を確認してから** 次の STEP に進みましょう。

### ファイルの場所

```
chapter18
├─ data
│   └─ tasks.csv
└─ kadai
    ├─ Kadai01.java   … 自分で作る
    └─ Task.java      … STEP 3 で作る
```

リポジトリのいちばん上のフォルダで実行してください（サンプルと同じです）。

---

## STEP 1：ファイルを読み込んで ArrayList に入れる（みんなで）

ファイルを1行ずつ読み込んで、`ArrayList<String>` に入れ、そのあと順番に表示します。

```java
package chapter18.kadai;

import java.io.BufferedReader;
import java.io.FileReader;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;

public class Kadai01 {
    public static void main(String[] args) throws Exception {
        ArrayList<String> lines = new ArrayList<String>();

        // ① ファイルを開く
        BufferedReader reader = new BufferedReader(
                new FileReader("chapter18/data/tasks.csv", StandardCharsets.UTF_8));

        // ② 1行ずつ読んで、ArrayList に入れる
        String line = reader.readLine();
        while (line != null) {
            lines.add(line);
            line = reader.readLine();
        }

        // ③ ファイルを閉じる
        reader.close();

        // ④ ArrayList から1つずつ取り出して表示する
        System.out.println("----タスク一覧----");
        for (String s : lines) {
            System.out.println(s);
        }
    }
}
```

**ポイント**

- 読み込みと表示を **分けて** います。
  ファイルはすぐに閉じて、あとは ArrayList の中身を使います。
- ArrayList に入れておけば、あとから **何回でも、好きな順番で** 使えます。

#### 実行結果

```text
----タスク一覧----
課題レポートを提出する,2026-11-10,0
Javaの復習をする,2026-11-12,1
教科書を読む,2026-11-15,0
プレゼン資料を作る,2026-11-20,0
```

## STEP 3：Task クラスを作って、見やすく表示する

今は `課題レポートを提出する,2026-11-10,0` のように、ファイルの1行がそのまま表示されています。
1行を **タイトル・期限・完了** に分けて、`Task` のインスタンスにしてから ArrayList に入れましょう。

(1) `chapter18/kadai/Task.java` を作ってください。

```java
package chapter18.kadai;

public class Task {
    private String title;
    private String deadline;
    private int isCompleted;

    // コンストラクタと、3つのゲッターを作る
}
```

(2) `Kadai01.java` を書きかえてください。

- `ArrayList<String>` を `ArrayList<Task>` にする
- 読み込んだ1行を `split(",")` で分けて、`Task` のインスタンスを作って ArrayList に入れる
- 「タイトル（期限 ○○）」の形で表示する

**ヒント**

```java
String[] items = line.split(",");   // "教科書を読む,2026-11-15,0" → ["教科書を読む", "2026-11-15", "0"]
String title = items[0];
String deadline = items[1];
int isCompleted = Integer.parseInt(items[2]);   // 文字列 "0" を 数値 0 に変換
```

- `file/Sample04.java` が参考になります。

## 自分で試してみよう

`tasks.csv` に1行追加して、もう一度実行してみましょう。

```text
部屋の掃除をする,2026-11-08,1
```

**プログラムは1文字も変えていないのに**、表示されるタスクや件数が変わるはずです。
データをプログラムの外（ファイル）に置くと、こういうことができるようになります。
