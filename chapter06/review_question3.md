## 発展問題：統計量を計算する

review_question2の問題に加えて、
さらに、7日間の気温データから、次の4つの統計量を計算して表示してください。

### 統計量について

| 日本語  | 英語                 | どんな値？                      | 計算式・求め方                                              |
| ---- | ------------------ | -------------------------- | ---------------------------------------------------- |
| 中央値  | Median             | データを小さい順に並べたとき、中央にくる値      | データを昇順に並べ、中央の値を求める                                   |
| 最頻値  | Mode               | データの中で、最も多く出現する値           | それぞれの値が何回出現するかを数え、最も回数が多い値を求める                       |
| 分散   | Variance           | データが平均値からどのくらいばらついているかを表す値 | それぞれのデータと平均値との差を求め、その差を二乗する。それらをすべて足し、データの個数で割る        |
| 標準偏差 | Standard Deviation | データのばらつきの大きさを表す値。分散の平方根    | 分散の平方根（√）を求める|

* 標準偏差を求めるときは、Javaの標準ライブラリ Math にある、平方根を求めるメソッドを使っても構いません。
また、メソッドを使わずに、自分で計算するロジックを考えて実装してもOKです。


### 期待される結果

```text
=== 1週間の気温 ===

1日目：28℃
2日目：30℃
3日目：27℃
4日目：31℃
5日目：29℃
6日目：32℃
7日目：33℃

平均気温：30.0℃
1週間で最も高かった気温：33℃

=== 統計量 ===

中央値：30.0℃
最頻値：なし
分散：4.0
標準偏差：2.0
```


## コラム
ちなみに、Pythonでは、標準ライブラリにこれらを求めるメソッドが用意されているため、簡単に計算することができます。

```python
import statistics

data = [10, 20, 20, 30, 40]


print(statistics.mean(data))      # 平均
print(statistics.median(data))    # 中央値
print(statistics.mode(data))      # 最頻値
print(statistics.pvariance(data)) # 分散（母分散）平均値との差の２乗の平均
print(statistics.pstdev(data))    # 標準偏差（母標準偏差）　√分散
```

Javaでは、標準ライブラリにこれらすべてを求めるメソッドは用意されていません。
そのため、外部ライブラリを利用するか、自分で計算するプログラムを作成する必要があります。

- java.lang.math
https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/lang/Math.html
