# 1. おにぎり売上ランキングを作ろう！

- フォルダ名は、　review-question1-2600xx(最後の６桁の数字は学籍番号)にしてください。
- ソースコードをコンパイルして、動作を確認した後、2つのJavaファイルと2つのクラスファイルが入ったフォルダをZIP形式にしてください。
  

## 問題

あるコンビニのおにぎりの、1週間の売上個数を調べました。

次の配列には、**1日目から7日目までのおにぎりの売上個数**が順番に保存されています。

```java
int[] sales = {35, 42, 28, 50, 45, 38, 52};
```

つまり、次のような売上を表しています。

| 日   |  売上 |
| --- | --: |
| 1日目 | 35個 |
| 2日目 | 42個 |
| 3日目 | 28個 |
| 4日目 | 50個 |
| 5日目 | 45個 |
| 6日目 | 38個 |
| 7日目 | 52個 |

この配列を使って、**1週間のおにぎりの売上個数、平均売上個数、そして最もおにぎりが売れた数**を表示するプログラムを作成しなさい。


## 条件

### 1．ファイルを分ける

プログラムを次の2つのファイルに分けること。

```text
Main.java
SalesUtility.java
```

### 2．Main.java

`Main.java` に次の配列を作成すること。

```java
int[] sales = {35, 42, 28, 50, 45, 38, 52};
```

この配列をメソッドに渡して処理すること。

---

### 3．SalesUtility.java

`SalesUtility.java` に次の3つのメソッドを作成すること。

```java
// 1日ごとのおにぎりの売上個数を表示するメソッド
public static void printSales(int[] sales)

// 1週間のおにぎりの平均売上個数を計算し、double型で返すメソッド
public static double average(int[] sales)

//1週間の中で、最も多く売れたおにぎりの数を調べ、その個数を int 型で返すメソッド
public static int getMaxSales(int[] sales)
```


プログラムを実行すると、以下のように表示されること。

```text
=== おにぎり売上 ===

1日目：35個
2日目：42個
3日目：28個
4日目：50個
5日目：45個
6日目：38個
7日目：52個

平均売上：41.42857142857143個

最もおにぎりが売れた個数：52個
```
