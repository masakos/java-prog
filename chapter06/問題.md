```java
public class ScoreApp {

    public static void main(String[] args) {

        int score = 75;

        System.out.println("判定：" + judge(score));
        System.out.println("5点加算：" + addBonus(score));
```

## 問題3：プログラムを一時停止する

次のプログラムは、数字を2秒ごとに表示したいプログラムです。しかし、現在は一瞬で表示されてしまいます。

Java APIで **`java.lang.Thread`** クラスを調べ、一時停止するメソッドを利用して、2秒ごとに表示されるように修正してください。

* Thread クラスには、プログラムの実行を一時停止するためのメソッドが用意されています。

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }
    }
}
```

**手順ヒント**

Java API Documentationを開く

ブラウザで
https://docs.oracle.com/en/java/javase/25/docs/api/

を開き、

右上の検索欄に以下入力する

* `java.lang.Thread`

Method Summary　に利用できるメソッドが一覧で載っているので、目的に合うメソッドを探す

APIで Thread.sleep() の仕様を調べると throws InterruptedException と書かれている。このため、sleep() を使うときは、InterruptedException を throws で宣言するか、try-catch などで処理する必要があります。 

| 書き方         | 意味                               |
| ----------- | -------------------------------- |
| `throws`    | **このメソッドが例外を発生させる可能性があることを宣言する** |
| `try-catch` | **発生した例外を受け取って処理する**             |


- throwsで宣言

```java
public static void main(String[] args) throws InterruptedException {

```


- try-catch

```java
try {
    Thread.sleep(2000);
} catch (InterruptedException e) {
    // 例外処理
}
```
